Model Architecture

This application uses a Logistic Regression machine learning model to predict customer churn. Logistic regression is a statistical method for analyzing a dataset in which there are one or more independent variables that determine an outcome.

The outcome is measured with a dichotomous variable (in this case, whether the customer will Churn or Stay). It is particularly well-suited for binary classification tasks where understanding the probability and interpretability of feature weights is important.

Pipeline Steps:

  • Data Extraction: Raw historical data loaded from CSV.
  • Preprocessing: Missing values handled, categorical variables encoded.
  • Scaling: StandardScaler applied to normalize continuous numerical features (tenure, monthly charges, total charges).
  • Training: Model fit using sklearn.linear_model.LogisticRegression.
  • Serialization: Model and scaler serialized via pickle for fast inference.
