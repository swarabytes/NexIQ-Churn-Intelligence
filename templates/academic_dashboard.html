Academic Research Methodology

Theoretical framework, data preprocessing pipelines, and evaluation protocols adhered to in this laboratory.

Supervised Churn Classification CRISP-DM

Models evaluate churn using holdout stratified splits (80/20) without SMOTE leakage on test partitions. Benchmarks compute Balanced Accuracy, Recall, and ROC-AUC under severe class imbalance (~6.1% churn rate).

Logistics Freight Regression Physical Modeling

Continuous estimation of order freight value based on physical weight, dimensional package volume ($L \times W \times H$), and seller/customer state origin-destination routing with L1/L2 regularization penalties.

Unsupervised Segmentation RFM Analysis

Partitions multi-order customers into personas (Champions, Loyal, At-Risk, Dormant). Evaluates mathematical cluster separation using the Silhouette Index ($K=2$ peak) against managerial interpretability ($K=4$).

Apriori Market Basket Analysis Sparse Matrix

Frequent itemset discovery on order transaction baskets. Explicitly addresses dataset sparsity (only ~0.75% multi-category orders) with tailored minimum support thresholds.

Multidimensional OLAP Modeling Analytical Cube

Data warehousing cubes supporting Roll-Up across time, Drill-Down into operational quarters, Slices on individual state jurisdictions, and Dices across multi-dimensional criteria.

Relational Schema Architecture Dimensional DW

Direct introspection of physical CSV relationships: Star Schema (denormalized fast reads), Snowflake (3NF sub-dimensions), and Fact Constellation (shared dimensions across orders and payments).
